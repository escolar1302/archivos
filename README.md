# Archivos

Nube personal para tener a mano PDF, documentos, imágenes y páginas HTML de actividades
en cualquier computadora, sin iniciar sesión en ninguna cuenta.

Se ve en https://escolar1302.github.io/archivos/

## Cómo se usa

1. Copiar los archivos dentro de esta carpeta (se pueden crear subcarpetas).
2. Hacer commit y subir (`git push`).
3. GitHub regenera solo `index.html` con el listado.

No subir datos personales ni sensibles: el repositorio es público.
